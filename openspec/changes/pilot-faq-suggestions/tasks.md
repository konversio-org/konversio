## Tasks

### Backend

1. - [x] **Migration** — create `pilot_faq_suggestions` (question string, answer text, embedding vector(1536), assistant + account references, language string defaulting from account locale handling, source_count integer default 0, status integer default 0) with a composite index on `(account_id, assistant_id, status, language)` and an ivfflat cosine index on the embedding; create `pilot_faq_observations` (account + conversation references, nullable faq_suggestion reference, generated_question string, generated_answer text, language, status integer default 0) with a partial unique index on `(conversation_id, faq_suggestion_id)` where the suggestion reference is present.
2. - [x] **Models** — add `Pilot::FaqSuggestion` (`app/models/pilot/faq_suggestion.rb`): belongs to assistant/account, has many observations (dependent delete), `has_neighbors :embedding, normalize: true`, status enum `open / approved / dismissed`, presence validations, account derived from assistant, embedding refresh via `Pilot::UpdateEmbeddingJob` on create/update while open when question or answer changed, scopes `ordered` (source_count desc, updated_at desc) and `by_language`. Add `Pilot::FaqObservation` (`app/models/pilot/faq_observation.rb`): belongs to account/conversation, optional suggestion, status enum `attached / discarded`, validations (attached requires a suggestion in the same account), account derived from conversation. Wire `has_many :faq_suggestions` onto `Pilot::Assistant` and the account concern.
3. - [x] **Matching service** — add the two-stage candidate matcher used by mining: embed `"<question>: <answer>"`, shortlist nearest neighbors under cosine distance 0.3 (small fixed limit, index scan disabled within the transaction so relation filters cannot hide matches), then a boolean LLM equivalence judgment per shortlisted record; a judgment call that fails (parse error, non-boolean verdict, LLM error) must raise so the job retries rather than silently misrouting.
4. - [x] **Rework mining persistence** — in `Pilot::Conversations::FaqMiningJob` replace `persist_survivors`/`create_response` with candidate routing: approved-knowledge match → discarded observation; dismissed suggestion match (same language) → discarded observation; open suggestion match (same language) → attach observation and increment `source_count` under a row lock (no-op if the conversation already observed that suggestion); no match → create open suggestion + attached observation. Attaching must verify the suggestion is still open and its question/answer have not changed since matching; on a concurrent-change conflict, re-route the candidate. Keep the existing transcript build, human-reply short-circuit, digest idempotency, and error swallowing.
5. - [x] **Language helper** — normalized language code for a conversation: account locale (fall back to default locale), hyphen/underscore variants collapsed to the primary subtag, lowercased.
6. - [x] **Approval service** — new `Pilot::FaqSuggestionApprovalService`: under a row lock, raise `ActiveRecord::RecordNotFound` unless open, apply optional question/answer attributes, create an approved `Pilot::AssistantResponse` from the final text, mark the suggestion approved, return the created response.
7. - [x] **Finder** — new permission-aware finder: administrators get all account suggestions; other agents get only suggestions with an observation on a conversation returned by `Conversations::PermissionFilterService`.
8. - [x] **Policy** — add `Pilot::FaqSuggestionPolicy` (`app/policies/pilot/faq_suggestion_policy.rb`) permitting index/show/update/approve/dismiss for account members; data scoping lives in the finder.
9. - [x] **Controller + views** — `Api::V1::Accounts::Pilot::FaqSuggestionsController` with `index` (paginated, 25/page, filters: assistant_id, status, ILIKE search over question/answer), `show` (suggestion plus up to 50 most recent permission-filtered observations with conversation ids/display ids), `update` (question/answer, open only, locked), `approve` (optional edits, via approval service), `dismiss` (open only, locked). Jbuilder partials for suggestion (id, account_id, question, answer, language, source_count, status, timestamps, embedded assistant) and observation (id, generated question/answer, language, status, created_at, conversation id/display_id). Index meta carries `total_count` and `page`.
10. - [x] **Routes** — add `resources :faq_suggestions, only: [:index, :show, :update]` with member `post :approve` and `post :dismiss` under the existing Pilot account namespace in `config/routes.rb`.
11. - [x] **Generation-quality gates review** — audit `Custom::Pilot::FaqMiningService`'s prompt against the requirement that answers come only from human-agent statements, only durable reusable knowledge qualifies, private/customer-specific facts are stripped, and an empty result is returned when nothing qualifies; close any gaps. needs investigation: which of these gates the current prompt already enforces.
